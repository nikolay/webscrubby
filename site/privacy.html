Privacy Policy

Last updated: May 10, 2026

Overview

WebScrubby is a Chrome extension that removes common tracking query parameters from URLs and provides a context-menu command for copying a scrubbed version of a link.

Data Processed

WebScrubby processes URLs, link destinations, and referrer hostnames in your browser so it can decide which parameters to remove. This processing happens locally in the extension using bundled cleanup rules.

Data Collection and Sharing

WebScrubby does not collect, sell, transmit, or share personal data with a WebScrubby server. The extension does not include analytics, ads, or remote tracking scripts.

Clipboard Use

WebScrubby writes to the clipboard only when you choose the Copy scrubbed link context-menu command.

Permissions

WebScrubby requests access to HTTP and HTTPS pages so it can inspect and clean link URLs where you browse. Browser navigation and request permissions are used to clean main-frame navigations and direct/no-referrer visits. Clipboard, context-menu, tab, and offscreen-document permissions support the explicit copy action.
