Clean the tracking bits out of links.

WebScrubby removes common campaign, ad, and social tracking query parameters before you open or copy a URL. It also unwraps redirect links from services like Facebook, Google, YouTube, LinkedIn, and Slack.

Scrubs as you browse

Known tracking parameters are removed from navigated links, including direct address-bar visits without a referrer.

Copy clean links

The right-click menu adds Copy scrubbed link, so pasted URLs stay focused on the destination instead of the tracker payload.

Unwraps redirects

Redirect wrappers are decoded structurally, then the embedded target URL is scrubbed just like a normal link.

Built to stay local.

WebScrubby does not send browsing data to a WebScrubby server. URL cleanup happens in the extension using bundled rules, and clipboard access is used only after you choose the context-menu copy action.
